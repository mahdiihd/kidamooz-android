# توسعه اپ مشترک اندروید و وب

ابتدا [راهنمای پروژه](../../../AGENTS.md)، [مشخصات](../../../spec.md) و برای قابلیت‌های پلتفرمی [راهنمای وب](../../../WEB.md) را بخوانید.

1. از مسیر مربوط در `src/app/app.routes.ts` به صفحه و سرویس مصرف‌شده برسید. مدل API و مبدل آن را پیش از تغییر داده بررسی کنید.
2. برای کاتالوگ و پخش، سرویس‌ها و storeهای فعلی را گسترش دهید؛ وضعیت موازی برای پخش یا کش نسازید مگر نیاز تغییر آن را ایجاب کند.
3. در ضبط صدا، اعلان، فایل و چرخه عمر، مسیر بومی و وب را جداگانه بررسی کنید. فراخوانی پلاگین بومی باید محافظ و جایگزین مناسب وب داشته باشد.
4. متن‌ها را با سرویس ترجمه، مسیرهای ورود را با محافظ‌ها و نمایش قابلیت را با تنظیمات محیط هماهنگ کنید.
5. `npm run lint` و `npm run build:pwa` را برای تغییر اجرایی اجرا کنید. رفتار مرتبط را با آزمون Karma و بررسی موبایل وب و دسکتاپ بسنجید.
6. اگر تغییر به پلتفرم بومی وابسته است، پس از ساخت و `npm run cap:sync` روی دستگاه یا شبیه‌ساز بررسی کنید؛ نبود ابزار دستگاه را صریح گزارش کنید.

خروجی `www/` محل پیاده‌سازی نیست. تغییرات service worker یا کش را با سناریوی به‌روزرسانی نسخه قبلی نیز بررسی کنید.
